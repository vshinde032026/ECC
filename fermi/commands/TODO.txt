`/fermi-*` slash commands — the human-facing triggers that launch workflows. A command is
a markdown file with a `description:` frontmatter line and a body of instructions.

When this folder has real commands, declare it in `.claude-plugin/plugin.json` as an
**array**: `"commands": ["./commands/"]`. (Not before — an empty declared path can fail
the validator.)
