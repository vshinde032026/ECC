# agents/ — TODO (Stage 1, the main folder)

Project-aware agents live here. Each is a **copy** of an ECC agent from `../../agents/`
with a hand-written `## Project context` section appended so it understands our repo.

We copy (never edit ECC's originals) so fermi stays self-contained and clone-and-go.

## What goes in a fermi agent

A markdown file with YAML frontmatter + instructions. Rules from the plugin schema:

- `tools:` is a **comma-separated scalar**, not a YAML list — e.g. `tools: Read, Grep, Glob`.
- Keep `name`, `description`, `tools`, `model` in the frontmatter.
- Agents are auto-discovered from this folder — do NOT list them in `plugin.json`.

## Anatomy

```markdown
---
name: fermi-code-reviewer
description: Reviews diffs against our conventions.
tools: Read, Grep, Glob
model: opus
---
<the base ECC agent instructions>

## Project context
- Stack & structure: <languages, framework, where code lives>
- Conventions: <the rules this agent must enforce>
- Requirements & gotchas: <what "correct" means here, what to never do>
```
